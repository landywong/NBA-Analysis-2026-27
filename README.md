# NBA-Analysis-2026-27
Data analysis &amp; prediction of the 2026-27 NBA season. (Using 2021-25 data)  
Uses BallDontLie API: https://www.balldontlie.io/  
  
Includes:
- API for raw data
- Dashboards
- Analysis predictions  

### Step 0- Designing Framework:
- Main Pitch: Which teams have the highest chance of making the playoffs?
- Offensive vs defensive influence; which has stronger correlation?
- Does high defense increase influence during playoff runs?
- Star players vs team synergy; which contributes more?

### Step 1- Fetching Data:
- Using player, team, and season game data
- Pulling from seasons 2021 to 2025
- Focus on player box scores for correlation analysis
